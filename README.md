# card-pack

Browser tools for designing trading-card packaging. Each tool is a self-contained folder:
open its `index.html` by double-clicking it — it works offline, no build step or server needed.

| Tool | What it does |
|---|---|
| [`01_boosterPack`](01_boosterPack/) | Live 3D preview of a booster pack: front / back artwork, pack film (metallic, foil, matte), artwork fill, foil textures, crimps and back flap, hover tilt and click-to-flip |

See each tool's README for image sizes and usage.
